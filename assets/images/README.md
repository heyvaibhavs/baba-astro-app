# Placeholder for Astro Logo

This directory should contain the logo.png file for the splash screen.

For now, the app uses a gradient circle with a star icon as a placeholder.

To add a custom logo:
1. Place your logo.png file in this assets/images/ directory
2. Make sure it's properly sized (preferably 512x512 pixels for best results)
3. The logo should have a transparent background for best appearance

The logo will be used in:
- Native splash screen
- Login screen
- Loading states
